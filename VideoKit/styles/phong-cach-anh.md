# Khối phong cách ảnh nhân vật

Dán khối này vào đầu mọi prompt ảnh để cả bộ nhân vật đồng nhất. Khi tạo nhân vật mới, luôn gửi kèm một nhân vật đã có làm ảnh tham chiếu phong cách.

```
Glossy cartoon vector illustration: smooth cel-shading with 2-3 tonal steps, soft white specular highlights on rounded surfaces, thin outline in a darker shade of each shape's own color (no black outline), large glossy expressive eyes with white catchlights, chubby rounded proportions, clean smooth edges, no textures.
```

Phần đuôi (khung và nền trong suốt):

```
Single subject centered, full body visible with a small margin, no text, no ground, no cast shadow, no extra props, completely transparent background.
```

Câu mở khi dùng ảnh tham chiếu:

```
Use the reference image ONLY as a style guide (rendering style, shading, outline, eye style, proportions' roundness). Do not copy the reference character. Draw a new subject:
```

Quy tắc màu trong video: đỏ chỉ để báo lỗi, xanh ngọc cho cái ổn/POP, hổ phách cho OOP. Nhân vật tránh đỏ và xanh lá; tránh thân quá tối vì chìm vào nền video `#0B1020`.
