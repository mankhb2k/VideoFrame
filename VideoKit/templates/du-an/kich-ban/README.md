# Kịch bản

Mỗi cảnh một file `canh-N-ten-canh.md`. Định dạng đang dùng:

- Dòng đầu: `# Cảnh N: Tên cảnh`
- Mỗi đoạn: `## Đoạn M: Tiêu đề (xx giây)`
- Trong đoạn: `**[Hình]** mô tả hình`, rồi `**[Lời dẫn]** “lời đọc”`, và các khối code nếu có.

Thời lượng ghi trong file chỉ là ước lượng; độ dài video do giọng đọc quyết định.
Đoạn nào không có `[Lời dẫn]` sẽ im tiếng: quyết định có viết thêm lời hay không trước khi tạo giọng.
